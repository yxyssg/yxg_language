YXG 语言简介

设计初衷

YXG 是一门为教学而生的编译型编程语言。它有四个设计目标：

  1. 足够简单——能够在有限时间内手写出完整的编译器
  2. 足够丰富——涵盖静态类型、面向对象、模块系统等现代语言特性
  3. 可调试——生成的汇编代码清晰可读，方便理解底层原理
  4. 自包含——除了 C 标准库和操作系统 API，不依赖任何第三方框架

YXG 的语法设计受到 C 语言的强烈影响，同时吸收了 Java/C# 的面向对象特性和脚本语言的便利性。它的编译器完全用 C 语言手写，没有任何自动生成工具（如 Yacc/Lex），是学习编译原理的绝佳实践项目。

下面是一个完整的 YXG 程序，定义了枚举、类、函数，实现了冒泡排序：

enum Color { Red, Green, Blue }

class Animal {
    string name;
    int age;

    pub void bark() {
        print name, " is making sound";
    }
}

int[] bubbleSort(int[] arr) {
    int n = arr.length;
    for int i = 0; i < n; i++ {
        for int j = 0; j < n - i - 1; j++ {
            if arr[j] > arr[j + 1] {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
        }
    }
    return arr;
}

int main(string[] args) {
    int[] nums = {5, 2, 8, 1, 9};
    Color c = Color.Green;
    int[] sorted = bubbleSort(nums);
    print "Sorted array:", sorted;

    Animal dog;
    dog.name = "Buddy";
    dog.age = 3;
    dog.bark();

    return 0;
}

类与面向对象

class Point {
    int x;
    int y;
    pri int z;

    pub Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    pub void move(int dx, int dy) {
        x = x + dx;
        y = y + dy;
    }

    pub int getX() { return x; }
    pub int getY() { return y; }
}

class ColorPoint : Point {
    int color;

    pub ColorPoint(int x, int y, int color) {
        this.x = x;
        this.y = y;
        this.color = color;
    }

    pub void display() {
        print "ColorPoint(", x, ",", y, ",", color, ")";
    }
}

Point p = new Point(10, 20);
p.move(5, -3);
ColorPoint cp = new ColorPoint(0, 0, 0xFF0000);
cp.display();

访问控制有三种：pub（公开）、pro（受保护，子类可访问）、pri（私有，仅类内可访问，自动生成 getter/setter）。this 关键字在方法内部指代当前实例。构造函数与类同名，没有返回类型。

限制与取舍

为了保持编译器可实现性，YXG 有意回避：

  • 无指针——用引用类型和数组替代
  • 无模板/泛型——保持类型系统简单
  • 无异常处理——通过返回值传递错误
  • 无操作符重载
  • 无函数重载——同作用域内函数名唯一
  • 仅 Win32 x86——代码生成器面向 Windows + NASM + MinGW
  • 无多线程

这些限制使得整个编译器可在约两万行 C 代码内完成，非常适合教学。

编译编译器

一键构建

项目提供了 Makefile，在项目根目录执行：

make

这会依次完成：

  1. 编译所有 .c 文件为目标文件
  2. 汇编所有运行时 .asm 文件
  3. 链接生成 yxg.exe

分步构建

如果需要调试，可以分步执行：

# 第一步：编译 C 源码
gcc -m32 -g -c src/main.c -o build/main.o
gcc -m32 -g -c src/Lexer.c -o build/Lexer.o
gcc -m32 -g -c src/parser.c -o build/parser.o
gcc -m32 -g -c src/Semantics.c -o build/Semantics.o
gcc -m32 -g -c src/IR.c -o build/IR.o
gcc -m32 -g -c src/CFG.c -o build/CFG.o
gcc -m32 -g -c src/SSA.c -o build/SSA.o
gcc -m32 -g -c src/regmap.c -o build/regmap.o
gcc -m32 -g -c src/Codegen_win32.c -o build/Codegen_win32.o
gcc -m32 -g -c src/Token.c -o build/Token.o
gcc -m32 -g -c src/Error.c -o build/Error.o
gcc -m32 -g -c src/YString.c -o build/YString.o

# 第二步：汇编运行时库
nasm -g -f win32 -O0 runtime/runtime_print.asm -o runtime_print.obj
nasm -g -f win32 -O0 runtime/runtime_string.asm -o runtime_string.obj
nasm -g -f win32 -O0 runtime/runtime_memory.asm -o runtime_memory.obj
nasm -g -f win32 -O0 runtime/runtime_gc.asm -o runtime_gc.obj
nasm -g -f win32 -O0 runtime/runtime_float.asm -o runtime_float.obj
nasm -g -f win32 -O0 runtime/runtime_array.asm -o runtime_array.obj
nasm -g -f win32 -O0 runtime/runtime_system.asm -o runtime_system.obj
nasm -g -f win32 -O0 runtime/runtime_bounds.asm -o runtime_bounds.obj

# 第三步：链接
gcc -m32 -g build/*.o build/*.obj -o yxg.exe

编译流程

当你执行 yxg hello.yxg 时，编译器内部经历了以下步骤：

hello.yxg
   │
   ▼
[词法分析]  → Token 序列
   │
   ▼
[语法分析]  → AST 抽象语法树
   │
   ▼
[语义分析]  → 标注类型的 AST + 符号表
   │
   ▼
[IR 生成]   → IR 中间表示链表
   │
   ▼
[CFG 构建]  → 基本块 + 控制流图
   │
   ▼
[SSA 构造]  → SSA 形式 + 优化 Pass
   │
   ▼
[寄存器分配] → 寄存器映射表
   │
   ▼
[代码生成]  → output.asm (NASM 汇编)
   │
   ▼
[NASM 汇编] → output.obj
   │
   ▼
[GCC 链接]  → output.exe (含运行时库)

可以使用 -a 参数停在汇编阶段，查看生成的 output.asm 来理解代码生成结果。

常见问题

Q: 提示 “nasm 不是内部或外部命令”

NASM 未安装或未添加到 PATH。重新运行 NASM 安装程序，确保勾选“添加到 PATH“选项，或手动将 NASM 安装目录添加到系统环境变量。

Q: 提示 “gcc 不是内部或外部命令”

MinGW 未安装或未添加到 PATH。检查 C:\msys64\ucrt64\bin 是否在 PATH 中。

Q: 链接时提示 undefined reference

通常是运行时库的 .obj 文件未正确生成。检查 runtime/ 目录下的 .asm 文件是否完整，重新执行 nasm 汇编步骤。

Q: 编译时提示 “无法解析的外部符号 _ExitProcess@4”

链接时缺少 Windows API 库。确保使用 MinGW 的 gcc 进行链接，它会自动链接 kernel32 等系统库。

Q: 生成的 exe 无法运行，提示缺少 DLL

YXG 编译器生成的是 32 位程序，需要 32 位运行时。在 64 位 Windows 上通常可以直接运行。如果提示缺少 libgcc_s_dw2-1.dll，将 MinGW 的 bin 目录添加到 PATH 即可。

逐行解析

第 1 行：int main()

int main() {
  • int 是返回值类型，表示这个函数返回一个整数
  • main 是函数名，它是程序的入口点，每个 YXG 程序必须有且仅有一个 main 函数
  • () 是参数列表，这里为空表示不接收命令行参数
  • { 表示函数体的开始

第 2 行：print “Hello, YXG!”

print "Hello, YXG!";
  • print 是 YXG 的内置语句，用于向控制台输出内容
  • “Hello, YXG!” 是一个字符串字面量
  • print 不需要括号，直接跟要打印的内容
  • ; 分号表示语句结束

第 3 行：return 0

return 0;
  • return 语句将值返回给调用者
  • 0 表示程序正常退出

第 4 行：}

函数体的结束。

基本用法

YXG 编译器的命令行格式为：

所有参数详解

-o：指定输出文件名

yxg hello.yxg -o myapp.exe

-r：编译后立即运行

yxg hello.yxg -r

yxg hello.yxg -r -- arg1 arg2

– 用于分隔编译器参数和程序参数。

-a：仅生成汇编文件

yxg hello.yxg -a

只执行编译流程的前半部分，生成 output.asm 后停止。不会调用 NASM 和 GCC 进行汇编和链接。这对于理解代码生成结果非常有用。

方式二：使用 import 语句

yxg main.yxg -o app.exe

  1. 当前目录
  2. lib/ 目录（相对于编译器所在位置）
  3. YXG_PATH 环境变量指定的目录（多个路径用分号分隔）

设置模块搜索路径

set YXG_PATH=C:\my_yxg_libs;D:\shared_yxg

$env:YXG_PATH = "C:\my_yxg_libs;D:\shared_yxg"

Linux / MSYS2：

export YXG_PATH=/home/user/yxg_libs:/opt/yxg_shared

编译器通过追踪 IR 中的指令类型来判断需要哪些运行时库。例如，遇到 IR_PRINT 指令时会设置 has_print = true，最终在链接阶段加入 runtime_print.obj。

基本类型

概述

YXG 是一门静态类型语言，每个变量在编译时就必须确定类型。共有 7 种基本类型：

类型关键字占用字节取值范围默认值
有符号整数int4-2147483648 ~ 21474836470
无符号整数uint40 ~ 42949672950
浮点数float4±1.18e-38 ~ ±3.4e+380.0
无符号浮点ufloat40 ~ 3.4e+380.0
字符char10 ~ 255‘\0’
布尔bool1true / falsefalse
字符串string4（指针）任意长度null

int：有符号整数

最常用的整数类型，32 位有符号：

int main() {
    int a = 42;
    int b = -100;
    int c = 0;

    int hex = 0xFF;
    int oct = 077;
    int bin = 0b1010;

    int sum = a + b;
    int diff = a - b;
    int prod = a * b;
    int quot = a / b;
    int mod = a % b;

    print sum, diff, prod, quot, mod;
    return 0;
}

整数除法向零截断。例如 7 / 3 = 2，-7 / 3 = -2。取模结果的符号与被除数相同。YXG 不检查整数溢出，行为与底层 CPU 一致。

uint：无符号整数

32 位无符号，不能存储负数：

int main() {
    uint a = 100;
    uint b = 200;
    uint max = 4294967295;

    uint sum = a + b;

    // uint x = -1;          // 编译错误！

    if a < b {
        print "a is less than b";
    }

    return 0;
}

uint 和 int 混合运算时，结果提升为 uint。比较时使用无符号比较指令。

float：浮点数

32 位 IEEE 754 单精度浮点：

int main() {
    float pi = 3.14159;
    float e = 2.71828;
    float small = 1.5e-3;
    float big = 6.02e23;

    float sum = pi + e;
    float area = pi * 5.0 * 5.0;

    float half = 1 / 2.0;
    float mixed = 3 + 0.14;

    print pi, area, half, mixed;
    return 0;
}

浮点数字面量必须包含小数点或使用科学计数法。整数与浮点混合运算时，整数自动提升为浮点。单精度约 7 位有效数字，存在舍入误差。

更复杂的数学运算可使用 Math 标准库：

import yxg.Math;

int main() {
    Math m = new Math();

    float x = m.sqrt(16.0);
    float y = m.sin(1.5708);
    float z = m.fabs(-3.14);

    print x, y, z;
    return 0;
}

Math 库还提供了 cos、tan、pow、min、max、clamp 以及随机数等功能。

ufloat：无符号浮点

与 float 相同的内存布局，但语义上不允许负值：

int main() {
    ufloat price = 19.99;
    ufloat distance = 100.5;

    // ufloat x = -1.5;      // 编译错误！

    float discount = 0.8;
    ufloat final_price = price * discount;

    print final_price;
    return 0;
}

ufloat 与 float 混合运算时，结果提升为 ufloat。编译器在语义分析阶段检查负值赋值。

char：字符

单字节，存储 0 到 255 之间的值：

int main() {
    char ch = 'A';
    char newline = '\n';
    char tab = '\t';
    char quote = '\"';
    char backslash = '\\';

    char next = ch + 1;
    int code = ch;

    if ch >= 'A' && ch <= 'Z' {
        print ch, "is uppercase";
    }

    print ch, next, code;
    return 0;
}

转义序列：

序列含义ASCII
\n换行10
\t制表符9
\反斜杠92
'单引号39
"双引号34
\0空字符0

char 和 int 可以互相赋值和运算。char 赋值给 int 时零扩展。

bool：布尔值

只有两个值：true 和 false：

int main() {
    bool flag = true;
    bool done = false;

    bool result = 10 > 5;
    bool equal = 3 == 4;

    bool and = true && false;
    bool or = true || false;
    bool not = !true;

    if flag {
        print "flag is true";
    }

    int asInt = true;
    int asInt2 = false;

    print result, and, or, not, asInt;
    return 0;
}

bool 在内存中占 1 字节。true 存储为 1，false 存储为 0。bool 可以隐式转换为 int，但 int 不能隐式转换为 bool（条件表达式除外）。

string：字符串

可变长度的字符序列。详细用法见字符串章节，这里展示基本操作：

import yxg.String;

int main() {
    String str = new String();

    string s1 = "Hello";
    string s2 = "World";

    string s3 = s1 + " " + s2;

    int len = str.len(s1);

    int c = str.charAt(s1, 0);

    if s1 == s2 {
        print "equal";
    } else {
        print "not equal";
    }

    print s3, len, c;
    return 0;
}

字符串在底层以 null 结尾，存储了长度信息。字符串是不可变的，每次拼接创建新对象，旧对象由 GC 回收。

变量与赋值

变量声明

YXG 中变量必须先声明后使用。声明变量的语法为：

类型 变量名 [= 初始值];

带初始化的声明

int main() {
    int age = 25;
    float price = 19.99;
    string name = "Alice";

    char grade = 'A';

    print age, price, name, active, grade;
    return 0;

不初始化的声明

    int count;

    string title;
    bool ready;

    count = 10;
    score = 95.5;
    title = "Manager";
    ready = true;

    print count, score, title, ready;
    return 0;
}

虽然 YXG 允许不初始化，但建议始终在声明时赋值，避免使用默认值带来的意外行为。

每条声明语句只能声明一个变量。不能像 C 语言那样用逗号分隔：

int a = 1;
int b = 2;
// int a = 1, b = 2;   // 错误！不支持

赋值

使用 = 进行赋值。赋值语句本身是一个表达式，返回被赋的值：

int main() {
    int x;
    int y;

    x = 10;
    y = x;

    int z = (x = 20);

    int a, b, c;
    a = b = c = 100;

    print x, y, z, a, b, c;
    return 0;
}

复合赋值运算符

YXG 支持所有常见的复合赋值：

int main() {
    int x = 10;

    x += 5;
    x -= 3;
    x *= 2;
    x /= 4;
    x %= 4;

    print x;
    return 0;
}

位运算的复合赋值：

int main() {
    int x = 0x0F;

    x <<= 4;
    x >>= 2;
    x ^= 0xFF;

    print x;
    return 0;
}

自增与自减

int main() {
    int a = 5;
    int b;

    b = ++a;
    print "前置++: a =", a, "b =", b;

    b = a++;
    print "后置++: a =", a, "b =", b;

    b = --a;
    print "前置--: a =", a, "b =", b;

    b = a--;
    print "后置--: a =", a, "b =", b;

    return 0;
}

输出：

前置++: a = 6 b = 6
后置++: a = 7 b = 6
前置--: a = 6 b = 6
后置--: a = 5 b = 6

int x = 5;

变量命名规则

变量名必须遵循以下规则：

  1. 只能包含字母（a-z、A-Z）、数字（0-9）和下划线（_）
  2. 不能以数字开头
  3. 区分大小写（name 和 Name 是不同的变量）
  4. 不能与关键字同名

合法示例：

int age;
int player1_score;
int _internal;
int MAX_VALUE;

不合法示例：

// int 1st_place;     // 不能以数字开头
// int my-var;        // 连字符不允许
// int class;         // class 是关键字
// int first name;    // 空格不允许

作用域

变量在声明它的代码块内可见。代码块由花括号 {} 界定：

int main() {
    int outer = 100;

    {
        int inner = 200;
        print outer;         // 可以访问外层变量
        print inner;         // 200
    }

    print outer;             // 100
    // print inner;          // 错误！inner 已超出作用域

    return 0;
}

内层作用域可以声明与外层同名的变量，这会遮蔽外层变量：

int main() {
    int x = 10;

    {
        int x = 20;
        print x;             // 20
    }

    print x;                 // 10（外层 x 未被修改）

    return 0;
}

函数参数的作用域是整个函数体：

void greet(string name) {
    print "Hello,", name;
}

常量

YXG 目前没有 const 关键字。约定用全大写命名表示不应修改的变量：

int main() {
    int MAX_SIZE = 100;
    float PI = 3.14159;
    string APP_NAME = "MyApp";

    print MAX_SIZE, PI, APP_NAME;
    return 0;
}

枚举成员也可以作为具名常量使用：

enum Limits {
    MAX_PLAYERS = 64,
    MAX_LEVEL = 99,
    TIMEOUT = 30
}

int main() {
    int players = Limits.MAX_PLAYERS;
    print "Max players:", players;
    return 0;
}

YXG 没有 typedef，但可以用类名作为类型：

class Point {
    int x;
    int y;
}

int main() {
    Point p;
    p.x = 10;
    p.y = 20;

    int mod = a % b;

    print sum, diff, prod, quot, mod;

    float x = 17.0;
    float y = 5.0;
    float fdiv = x / y;
    // float fmod = x % y;   // 错误：浮点不支持 % 运算符

    print fdiv;
    return 0;
}

整数除法向零截断：7 / 3 = 2，-7 / 3 = -2。

取模结果的符号与被除数相同：-17 % 5 = -2，17 % -5 = 2。

% 运算符只适用于整数类型（int、uint、char）。浮点数取模需使用内置函数。

比较运算符

比较运算的结果是 bool 类型：

int main() {
    int a = 10;
    int b = 20;

    bool eq = a == b;
    bool ne = a != b;
    bool lt = a < b;
    bool gt = a > b;
    bool le = a <= b;
    bool ge = a >= b;

    print eq, ne, lt, gt, le, ge;

    string s1 = "apple";
    string s2 = "banana";
    bool strCmp = s1 == s2;
    bool strLess = s1 < s2;

    print strCmp, strLess;
    return 0;
}

字符串比较按字典序逐字符进行。== 和 != 比较字符串内容，而不是地址。

逻辑运算符

int main() {
    bool a = true;
    bool b = false;

    bool and = a && b;
    bool or = a || b;
    bool not = !a;

    print and, or, not;

    // 短路求值
    int x = 0;
    bool result = x != 0 && 10 / x > 5;
    // 由于 x == 0，左侧为 false，右侧不会执行

    print result;
    return 0;
}

&& 和 || 使用短路求值：

  • 对于 A && B，如果 A 为 false，B 不会求值
  • 对于 A || B，如果 A 为 true，B 不会求值

位运算符

位运算符将操作数视为二进制位序列：

int main() {
    int a = 0x0F;
    int b = 0x3C;

    int and = a & b;
    int or = a | b;
    int xor = a ^ b;
    int not = ~a;

    int shl = a << 2;
    int shr = b >> 2;

    print and, or, xor, not, shl, shr;
    return 0;
}

注意事项：

  • ~ 按位取反，结果与操作数类型相关
  • << 左移，低位补 0

  • 对有符号数使用算术右移（高位补符号位），对无符号数使用逻辑右移（高位补 0）

  • 位运算符要求操作数为整数类型（int、uint、char、bool）

赋值运算符

基本赋值 = 已在前一章介绍。复合赋值将运算与赋值合并：

int main() {
    int x = 10;

    x += 5;
    x -= 3;
    x *= 2;
    x /= 4;
    x %= 4;
    x <<= 2;
    x >>= 1;
    x ^= 0xFF;

    print x;
    return 0;
}

赋值表达式的值是赋值后左操作数的值：

int a;
int b = (a = 5) + 3;     // a = 5, b = 8

自增自减运算符

int main() {
    int x = 5;

    int a = ++x;
    int b = x++;
    int c = --x;
    int d = x--;

    print a, b, c, d, x;
    return 0;
}

输出：

6 6 6 6 5

自增自减只能用于变量（左值），不能用于字面量或表达式：

int x = 5;
// 5++;           // 错误
// (x + 1)++;     // 错误

三目运算符

三目运算符 ? : 是 YXG 中唯一的三个操作数运算符，用于根据条件选择两个值之一：

条件 ? 为真时的值 : 为假时的值

基本用法

int main() {
    int a = 10;
    int b = 20;

    int max = a > b ? a : b;
    print "max:", max;                   // max: 20

    int min = a < b ? a : b;
    print "min:", min;                   // min: 10

    return 0;
}

嵌套三目

三目运算符是右结合的，可以嵌套使用：

int main() {
    int a = 10;
    int b = 20;

    // 等价于 a > b ? 1 : (a == b ? 0 : -1)
    int result = a > b ? 1 : a == b ? 0 : -1;
    print result;                        // -1

    // 多分支选择
    int score = 85;
    string grade = score >= 90 ? "A" :
                   score >= 80 ? "B" :
                   score >= 70 ? "C" :
                   score >= 60 ? "D" : "F";
    print grade;                         // B

    return 0;
}

三目作为表达式的一部分

三目运算符可以嵌入到更大的表达式中：

int main() {
    int a = 10;
    int b = 20;

    int c = (a < b ? a : b) + 5;
    print c;                             // 15

    // 在函数参数中使用
    print "The larger is", a > b ? a : b;

    return 0;
}

不同分支的类型提升

当两个分支的类型不同时，结果类型会自动提升：

int main() {
    int a = 10;
    int b = 5;

    // int 和 float → 结果为 float
    float f = a > b ? 3.14 : 2;
    print f;                             // 3.140000

    // int 和 char → 结果为 int
    int c = a > b ? 65 : 'Z';
    print c;                             // 65

    // string 和 char → 结果为 string
    string s = a > b ? "hello" : 'X';
    print s;                             // hello

    return 0;
}

类型提升规则与二元运算一致。

三目与 if/else 对比

三目运算符是表达式，可以出现在任何需要值的地方；if/else 是语句，不能直接返回值：

// 三目：简洁，适合简单条件
int max = a > b ? a : b;

// if/else：适合复杂逻辑
int max2;
if a > b {
    max2 = a;
} else {
    max2 = b;
}

选择建议：

  • 简单的二选一赋值，用三目
  • 需要执行多条语句，用 if/else
  • 嵌套超过两层，用 if/else if 更清晰

字符串拼接

int main() {

    string s4 = "Pi: " + 3.14;

}

常见错误

除零错误

int x = 10;
int y = 0;
// int z = x / y;       // 编译时警告或运行时崩溃

如果除数是字面量 0，编译器会报错。如果是变量且值为 0，运行时会产生硬件异常。

赋值与比较混淆

int x = 5;
if x = 10 {              // 可能本意是 x == 10

}

= 是赋值，== 是比较。在条件中使用 = 通常是一个 bug。

位运算符优先级

int x = 5;

控制流

概述

控制流语句决定程序的执行路径。YXG 提供了以下控制流结构：

语句用途
if / else if / else条件分支
switch / case多分支选择
while前置条件循环
do-while后置条件循环
for计数循环
foreach数组遍历循环
break跳出循环或 switch
continue跳过本次迭代
return从函数返回

条件语句的选择

根据不同场景选择合适的条件语句：

int score = 85;

// 简单的是/否判断 → if/else
if score >= 60 {
    print "及格";
} else {
    print "不及格";
}

// 多个范围判断 → if/else if/else
if score >= 90 {
    print "优秀";
} else if score >= 80 {
    print "良好";
} else if score >= 70 {
    print "中等";
} else if score >= 60 {
    print "及格";
} else {
    print "不及格";
}

// 单个值的多个匹配 → switch/case
int day = 3;
switch day {
    case 1: print "Monday"; break;
    case 2: print "Tuesday"; break;
    case 3: print "Wednesday"; break;
    default: print "Unknown";
}

循环语句的选择

int[] arr = {1, 2, 3, 4, 5};

// 已知循环次数 → for
for int i = 0; i < 5; i++ {
    print i;
}

// 遍历数组所有元素 → foreach
for int v : arr {
    print v;
}

// 条件未知，可能零次 → while
int i = 0;
while i < arr.length && arr[i] < 10 {
    print arr[i];
    i++;
}

// 至少执行一次 → do-while
int input;
do {
    input = 5;
} while input < 0 || input > 100;

break 与 continue

break 立即终止当前循环或 switch：

for int i = 0; i < 10; i++ {
    if i == 5 {
        break;
    }
    print i;
}

continue 跳过本次迭代的剩余部分：

for int i = 0; i < 10; i++ {
    if i % 2 == 0 {
        continue;
    }
    print i;
}

在嵌套结构中，break 和 continue 只影响最内层的循环或 switch。

条件表达式

所有条件语句的条件必须是 bool 类型：

int x = 10;
// if x { ... }            // 错误！int 不能作为条件
if x != 0 { ... }          // 正确

string s = "hello";
if s != "" { ... }         // 正确

bool flag = true;
if flag { ... }            // 正确

if x > 5 && y < 20 { ... } // 正确

代码块与作用域

控制流语句创建新的作用域：

int x = 10;

if x > 5 {
    int y = 20;
    print x, y;
}
// print y;                 // 错误！y 已超出作用域

for int i = 0; i < 5; i++ {
    print i;
}
// print i;                 // 错误！i 已超出作用域

控制流：if / else if / else

基本 if 语句

if 语句根据条件决定是否执行代码块。条件直接跟在 if 后面，不需要括号：

int main() {
    int score = 85;

    if score >= 60 {
        print "及格";
    }

    return 0;
}

条件必须是一个 bool 类型的表达式。int 不能直接作为条件：

int x = 10;
// if x { ... }            // 错误！x 是 int，不是 bool
if x != 0 { ... }          // 正确

if / else

int main() {
    int score = 55;

    if score >= 60 {
        print "及格";
    } else {
        print "不及格";
    }

    return 0;
}

else 部分是可选的。每个 if 最多有一个 else。

if / else if / else

多个条件分支使用 else if：

int main() {
    int score = 85;

    if score >= 90 {
        print "优秀";
    } else if score >= 80 {
        print "良好";
    } else if score >= 70 {
        print "中等";
    } else if score >= 60 {
        print "及格";
    } else {
        print "不及格";
    }

    return 0;
}

else if 可以有任意多个。条件按顺序检查，第一个为真的分支被执行，后续分支被跳过。

嵌套 if

if 语句可以嵌套：

int main() {
    int age = 25;
    bool hasTicket = true;

    if age >= 18 {
        if hasTicket {
            print "欢迎入场";
        } else {
            print "请先购票";
        }
    } else {
        print "未成年人不得入场";
    }

    return 0;
}

代码块与单条语句

如果分支只有一条语句，花括号可以省略：

int main() {
    int x = 10;

    if x > 5
        print "大于 5";
    else
        print "小于等于 5";

    return 0;
}

但建议始终使用花括号，避免悬挂 else 问题。YXG 中 else 始终与最近的未匹配 if 配对。

条件表达式

条件可以是任意返回 bool 的表达式：

int main() {
    int a = 10;
    int b = 20;

    if a < b { print "a < b"; }
    if a > 0 && b > 0 { print "both positive"; }
    if a < 0 || b < 0 { print "at least one negative"; }
    if !(a > b) { print "a <= b"; }

    bool isEven(int n) {
        return n % 2 == 0;
    }

    if isEven(a) { print "a is even"; }

    return 0;
}

三目运算符与 if/else

对于简单的二选一赋值，三目运算符更简洁：

int a = 10;
int b = 20;

int max = a > b ? a : b;

int max2;
if a > b {
    max2 = a;
} else {
    max2 = b;
}

需要执行多条语句时，必须使用 if/else。

常见模式

提前返回

int getGradeLevel(int score) {
    if score < 0 || score > 100 {
        return -1;
    }

    if score >= 90 { return 5; }
    if score >= 80 { return 4; }
    if score >= 70 { return 3; }
    if score >= 60 { return 2; }
    return 1;
}

范围检查

int main() {
    int age = 25;

    if age >= 0 && age <= 12 {
        print "儿童";
    } else if age >= 13 && age <= 17 {
        print "青少年";
    } else if age >= 18 && age <= 64 {
        print "成人";
    } else {
        print "老年";
    }

    return 0;
}

输入验证

import yxg.String;

int main() {
    String str = new String();
    string input = "admin";

    if input == "" {
        print "输入不能为空";
    } else if str.len(input) < 3 {
        print "输入太短";
    } else if str.len(input) > 20 {
        print "输入太长";
    } else {
        print "输入有效:", input;
    }

    return 0;
}

常见错误

条件不是布尔类型

int x = 10;
// if x { ... }            // 错误！
// error[E3020]: condition must be boolean, got 'int'

忘记花括号导致逻辑错误

if score >= 60
    print "及格";
    print "恭喜！";         // 这行不受 if 控制，总会执行

缩进不决定代码块，只有花括号决定。建议始终使用花括号。

控制流：switch / case

基本语法

switch 语句根据一个整数值选择执行不同的分支。条件直接跟在 switch 后面，不需要括号：

int main() {
    int day = 3;

    switch day {
        case 1: print "Monday"; break;
        case 2: print "Tuesday"; break;
        case 3: print "Wednesday"; break;
        case 4: print "Thursday"; break;
        case 5: print "Friday"; break;
        case 6: print "Saturday"; break;
        case 7: print "Sunday"; break;
        default: print "Invalid day";
    }

    return 0;
}

输出：

Wednesday

switch 详解

条件表达式

switch 的条件必须是整数类型（int、uint、char、bool）：

int main() {
    char grade = 'B';

    switch grade {
        case 'A': print "优秀"; break;
        case 'B': print "良好"; break;
        case 'C': print "中等"; break;
        case 'D': print "及格"; break;
        case 'F': print "不及格"; break;
        default: print "无效等级";
    }

    return 0;
}

float 和 string 不能用于 switch。

case 值

case 的值必须是编译时常量（字面量或枚举成员）：

int main() {
    int x = 2;

    switch x {
        case 1:
            print "one";
            break;
        case 2:
            print "two";
            break;
        // case x:        // 错误！x 是变量，不是常量
        //     break;
    }

    return 0;
}

break 语句

每个 case 必须显式使用 break 退出，YXG 不会自动穿透：

int main() {
    int x = 1;

    switch x {
        case 1:
            print "one";
            break;
        case 2:
            print "two";
            break;
    }

    return 0;
}

多个 case 共享同一段代码时，让它们连续排列：

int main() {
    int day = 6;

    switch day {
        case 1:
        case 2:
        case 3:
        case 4:
        case 5:
            print "工作日";
            break;
        case 6:
        case 7:
            print "周末";
            break;
        default:
            print "无效";
    }

    return 0;
}

输出：

周末

default 分支

default 分支在所有 case 都不匹配时执行，它是可选的：

int main() {
    int code = 999;

    switch code {
        case 200: print "成功"; break;
        case 404: print "未找到"; break;
        case 500: print "服务器错误"; break;
        default: print "未知状态码:", code;
    }

    return 0;
}

输出：

未知状态码: 999

与枚举配合

enum Color { Red, Green, Blue, Yellow }

int main() {
    Color c = Color.Green;

    switch c {
        case Color.Red:    print "红色"; break;
        case Color.Green:  print "绿色"; break;
        case Color.Blue:   print "蓝色"; break;
        case Color.Yellow: print "黄色"; break;
        default:           print "未知颜色";
    }

    return 0;
}

嵌套 switch

switch 可以嵌套，内层的 break 只跳出内层 switch：

int main() {
    int category = 1;
    int item = 2;

    switch category {
        case 1:
            print "电子产品";
            switch item {
                case 1: print "手机"; break;
                case 2: print "电脑"; break;
                default: print "其他电子产品";
            }
            break;
        case 2:
            print "食品";
            switch item {
                case 1: print "水果"; break;
                case 2: print "蔬菜"; break;
                default: print "其他食品";
            }
            break;
        default:
            print "未知分类";
    }

    return 0;
}

输出：

电子产品
电脑

switch 与 if 的选择

场景推荐
判断范围（>、<）if / else if
判断相等（多个离散值）switch
复杂逻辑条件if / else if
枚举类型匹配switch

常见错误

忘记 break

switch x {
    case 1:
        print "one";

        print "two";

    case 1: print "one"; break;
    case 1: print "also one"; break;    // 错误！

编译器报错：

// switch s { ... }         // 错误！string 不能用于 switch

控制流：while / do-while 循环

while 循环

while 循环在条件为真时重复执行代码块。条件直接跟在 while 后面，不需要括号：

int main() {
    int count = 0;

    while count < 5 {
        print "count =", count;
        count++;
    }

    print "循环结束";
    return 0;
}

输出：

count = 0
count = 1
count = 2
count = 3
count = 4
循环结束

如果条件一开始就是 false，循环体一次也不执行：

int main() {
    int x = 10;

    while x < 5 {
        print "这行永远不会执行";
    }

    print "直接到这里";
    return 0;
}

循环中的 break

break 语句立即终止循环：

int main() {
    int i = 0;

    while true {
        i++;
        print i;

        if i >= 5 {
            break;
        }
    }

    print "循环结束, i =", i;
    return 0;
}

输出：

1
2
3
4
5
循环结束, i = 5

循环中的 continue

continue 跳过本次循环的剩余部分，直接进入下一次条件检查：

int main() {
    int i = 0;

    while i < 10 {
        i++;

        if i % 2 == 0 {
            continue;
        }

        print i;

do-while 先执行循环体，再检查条件。循环体至少执行一次：

int main() {
    int count = 0;

    do {
        print "count =", count;
        count++;
    } while count < 5;

    print "循环结束";
    return 0;
}

即使条件一开始就是 false，循环体也会执行一次：

int main() {
    int x = 10;

    do {
        print "至少执行一次, x =", x;
    } while x < 5;

    return 0;
}

输出：

至少执行一次, x = 10

int main() {
    int a = 0;
    while a > 0 {
        print "while: 不会执行";
    }

    int b = 0;
    do {
        print "do-while: 会执行一次";
    } while b > 0;

    return 0;
}

输出：

do-while: 会执行一次

  • 循环体可能一次都不执行，用 while
  • 循环体至少执行一次（如输入验证），用 do-while

控制流：for 循环

基本语法

for 循环将初始化、条件判断和更新操作集中在一行。各部分用分号分隔，条件不需要括号：

int main() {
    for int i = 0; i < 5; i++ {
        print "i =", i;
    }

    print "循环结束";
    return 0;
}

输出：

i = 0
i = 1
i = 2
i = 3
i = 4
循环结束

执行流程：

  1. 执行初始化（只执行一次）
  2. 检查条件，如果为 false 则退出
  3. 执行循环体
  4. 执行更新
  5. 回到步骤 2

各部分详解

初始化

初始化部分在循环开始前执行一次。通常用于声明和初始化循环变量：

for int i = 0; ...       // i 的作用域仅限于 for 循环内
for int i = 10; ...      // 可以从任意值开始
for int i = n - 1; ...   // 可以使用表达式

初始化部分声明的变量作用域仅限于 for 循环内：

int main() {
    for int i = 0; i < 3; i++ {
        print i;
    }
    // print i;            // 错误！i 已超出作用域
    return 0;
}

也可以使用已存在的变量：

int main() {
    int i;
    for i = 0; i < 5; i++ {
        print i;
    }
    print "最终 i =", i;
    return 0;
}

初始化部分可以留空：

int main() {
    int i = 0;
    for ; i < 5; i++ {
        print i;
    }
    return 0;
}

条件

条件在每次迭代开始前检查。如果为 false，循环终止：

for int i = 0; i < 10; i++
for int i = 10; i > 0; i--
for int i = 0; i < n; i += 2

条件可以留空，表示始终为 true（无限循环）：

for ;; {
    print "loop";
    break;
}

更新

更新在每次循环体执行完后执行：

for int i = 0; i < 10; i++
for int i = 0; i < 10; i += 2
for int i = 10; i > 0; i--

更新部分可以留空，在循环体中手动更新：

for int i = 0; i < 10; {
    print i;
    i += 2;
}

循环中的 break 和 continue

break 立即终止整个循环：

int main() {
    for int i = 0; i < 10; i++ {
        if i == 5 {
            break;
        }
        print i;
    }
    return 0;
}

输出：

0
1
2
3
4

continue 跳过本次迭代的剩余部分：

int main() {
    for int i = 0; i < 10; i++ {
        if i % 2 == 0 {
            continue;
        }
        print i;
    }
    return 0;
}

输出：

1
3
5
7
9

foreach 与 for 对比

int main() {
    int[] arr = {10, 20, 30, 40, 50};

    // 传统 for：需要索引时使用
    for int i = 0; i < arr.length; i++ {
        print "arr[", i, "] =", arr[i];

    // foreach：只读遍历时更简洁

  • 需要索引时用 for（如修改数组元素、需要知道位置）
  • 只读遍历时用 foreach（更简洁，不会越界）
  • 倒序遍历用 for
  • 跳跃遍历用 for

循环中的 break 和 continue

int main() {
    int[] arr = {1, 3, 5, 8, 10, 12};

    // 找到第一个偶数
    for int v : arr {
        if v % 2 == 0 {
            print "第一个偶数:", v;
            break;
        }
    }

    // 只打印奇数
    for int v : arr {
        if v % 2 == 0 {
            continue;
        }
        print "奇数:", v;
    }

    return 0;
}

奇数: 1
奇数: 3
奇数: 5

求和

            count++;
        }

注意事项

不能修改数组元素

foreach 中的循环变量是数组元素的副本，修改它不会影响原数组：

int main() {
    int[] arr = {1, 2, 3, 4, 5};

    for int v : arr {
        v = v * 2;               // 只修改了副本，不影响 arr
    }

    for int v : arr {
        print v;                 // 仍然是 1, 2, 3, 4, 5
    }

    return 0;
}

需要修改数组元素时使用传统 for 循环：

for int i = 0; i < arr.length; i++ {
    arr[i] = arr[i] * 2;
}

不能获取索引

foreach 不提供索引信息。如果需要索引，使用传统 for。

遍历时不能修改数组长度

数组长度在循环开始时确定，遍历期间不能增减元素。

常见错误

类型不匹配

float[] arr = {1.5, 2.5, 3.5};
// for int v : arr { ... }       // 错误！类型不匹配
for float v : arr { ... }        // 正确

遍历非数组类型

int x = 42;
// for v : x { ... }             // 错误！x 不是数组

foreach 只能用于数组和字符串。

函数

定义函数

函数是组织代码的基本单元。定义函数的语法：

返回类型 函数名(参数列表) {
    函数体
    return 返回值;
}

一个简单的例子：

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(3, 5);
    print "3 + 5 =", result;
    return 0;
}

输出：

3 + 5 = 8

参数

函数可以接收零个或多个参数，每个参数需要声明类型和名称：

// 无参数
void sayHello() {
    print "Hello!";
}

// 一个参数
void greet(string name) {
    print "Hello,", name;
}

// 多个参数
int max(int a, int b, int c) {
    if a >= b && a >= c { return a; }
    if b >= a && b >= c { return b; }
    return c;
}

参数之间用逗号分隔。调用时实参按位置顺序传递：

int main() {
    sayHello();
    greet("Alice");
    int m = max(10, 25, 15);
    print "最大值:", m;
    return 0;
}

返回值

函数通过 return 语句返回值。返回类型必须与声明一致：

int getNumber() {
    return 42;
}

float getPi() {
    return 3.14159;
}

string getMessage() {
    return "Hello, World!";
}

bool isPositive(int n) {
    return n > 0;
}

void 函数没有返回值，return 语句可选：

void printTwice(string s) {
    print s;
    print s;
}

void maybeReturn(int x) {
    if x < 0 {
        return;
    }
    print "x is non-negative:", x;
}

数组参数与返回值

函数可以接收和返回数组：

int sum(int[] arr) {
    int total = 0;
    for int v : arr {
        total += v;
    }
    return total;
}

int[] makeArray(int size) {
    int[] arr = new int[size];
    for int i = 0; i < size; i++ {
        arr[i] = i * 2;
    }
    return arr;
}

int main() {
    int[] nums = {1, 2, 3, 4, 5};
    int s = sum(nums);
    print "总和:", s;

    int[] evens = makeArray(5);
    for int v : evens {
        print v;
    }

    return 0;
}

总和: 15
0

4
6
8

多维数组也可以作为参数：

void printMatrix(int[][] matrix) {
    for int[] row : matrix {

            print elem;
        }
    }
}

函数重载

YXG 不支持函数重载。同一作用域内函数名必须唯一：

// int add(int a, int b) { return a + b; }
// float add(float a, float b) { return a + b; }   // 错误！重复定义

如果需要处理不同类型，使用不同的函数名：

int addInt(int a, int b) { return a + b; }
float addFloat(float a, float b) { return a + b; }

递归

函数可以调用自身：

int factorial(int n) {
    if n <= 1 {
        return 1;
    }
    return n * factorial(n - 1);
}

int fibonacci(int n) {
    if n <= 1 {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    print "5! =", factorial(5);
    print "fib(7) =", fibonacci(7);
    return 0;
}

输出：

5! = 120
fib(7) = 13

递归深度受限于栈空间。YXG 没有尾递归优化，深度递归可能导致栈溢出。

main 函数

main 函数是程序的入口点，每个程序必须有且仅有一个。返回类型必须是 int，return 0 表示正常退出。

无参数版本

    print "Hello, YXG!";
    return 0;
}

接收命令行参数

main 函数可以声明为接收 string[] 参数来获取命令行参数：

int main(string[] args) {

局部变量与作用域

函数内部声明的变量是局部变量，只在函数内可见：

void myFunc() {
    int x = 10;
    print x;
}

int main() {
    myFunc();
    // print x;             // 错误！x 不在作用域内

}

函数参数也是局部变量，传递方式是值传递：

void test(int n) {
    n = n + 1;
    print "函数内:", n;
}

int main() {
    int a = 5;
    test(a);
    print "函数外:", a;
    return 0;
}

输出：

函数内: 6
函数外: 5

对于基本类型，传递的是值的副本。对于数组和类实例，传递的是引用的副本（但引用指向同一对象）。

int main() {
    int[] nums = {1, 2, 3, 4, 5};
    doubleElements(nums);

        print v;
    }

    return 0;
}

4
6

        }

    c.increment();

    print m.sqrt(25.0);
    print sys.time();

    return 0;
}

import yxg.String 等价于查找 yxg/String.yxg。

  1. 当前工作目录
  2. 编译器所在目录下的 lib/ 子目录
  3. YXG_PATH 环境变量指定的目录（多个路径用分号分隔）

重复导入

同一个模块只会被导入一次。编译器内部维护了已导入模块的列表，后续对同一模块的 import 会被忽略：

import yxg.String;

    String str = new String();
    print str.len("hello");
    return 0;
}

YXG 不支持循环导入。如果 A.yxg import B.yxg，而 B.yxg 又 import A.yxg，编译器会检测到并报错。

概述

输入输出

3.141590
true
A

[1, 2, 3]

int main() {

各阶段职责

词法分析（Lexer）

将源代码字符串转换为 Token 序列。Token 是编译器内部的最小语义单元，例如关键字 int、标识符 main、运算符 +、字面量 42 等。

输入：

int x = 10;

输出：

TOKEN_INT  TOKEN_IDENTIFIER("x")  TOKEN_ASSIGN  TOKEN_NUMBER("10")  TOKEN_SEMICOLON

语法分析（Parser）

将 Token 序列按照语法规则组织成抽象语法树（AST）。AST 以树形结构表示程序的语法层次。

输入：

int x = 10;

输出：

AST_VAR
├── type: int
├── name: x
└── value: AST_LITERAL(10)

语义分析（Semantics）

遍历 AST，进行类型检查、符号表管理、作用域分析。标注每个节点的数据类型，检查类型匹配、变量是否声明等。

输入：未标注类型的 AST

输出：标注了类型的 AST + 完整的符号表

IR 生成（IR Gen）

将标注类型的 AST 转换为三地址码形式的中间表示（IR）。IR 是一种接近汇编但独立于具体硬件的线性指令序列。

输入：AST

输出：

.t1 = 10
x = .t1

CFG 构建

将线性 IR 链表划分为基本块，构建控制流图。基本块是一段顺序执行的 IR 序列，以跳转或返回结尾。

输入：IR 链表

输出：基本块数组 + 前驱/后继关系

SSA 构造

将 IR 转换为静态单赋值形式，并进行优化。SSA 要求每个变量只被赋值一次，通过 φ 节点合并不同路径的值。

输入：普通 IR + CFG

输出：SSA 形式 IR + 优化后的 IR

寄存器分配

将 IR 中的虚拟变量映射到物理寄存器（eax、ecx、edx、ebx、esi、edi）。使用 Chaitin-Briggs 图着色算法。

输入：SSA 形式 IR + 活跃区间

输出：寄存器映射表

代码生成

将 IR 指令翻译为 x86 NASM 汇编代码。处理函数序言/结语、调用约定、数据段布局等。

输入：IR + 寄存器映射

输出：output.asm

汇编与链接

调用 NASM 将汇编文件汇编为目标文件，再调用 GCC 链接运行时库生成可执行文件。

输入：output.asm + 运行时 .obj 文件

输出：output.exe

数据结构总览

概述

YXG 编译器在编译过程中使用多种核心数据结构来承载不同阶段的信息。理解这些数据结构是理解整个编译器架构的关键。

数据结构的流转

Token ──组成──▶ ASTNode ──转换──▶ IR
  │                │                │
  │                ▼                ▼
  │          Symbol Table        CFG (BasicBlock[])
  │          (符号表)            (控制流图)
  │                                  │
  │                                  ▼
  │                            SSA 形式 IR
  │                                  │
  │                                  ▼
  │                            RegMap (寄存器映射)

Token（词法单元）

Token 是词法分析器的输出，代表源代码中最小的语义单元。定义在 Token.h：

typedef struct Token {
    char* value;        // 词法值，如 "int"、"42"、"x"
    TokenType type;     // 词法类型，如 TOKEN_INT、TOKEN_NUMBER
    int line;           // 所在行号
    int column;         // 所在列号
} Token;

TokenType 枚举包含约 80 种类型，涵盖关键字、运算符、字面量、分隔符等。

ASTNode（抽象语法树节点）

ASTNode 是语法分析器的输出，以树形结构表示程序的语法层次。定义在 AST.h：

typedef struct ASTNODE {
    ASTType type;       // 节点类型
    Token value;        // 关联的词法单元
    struct ASTNODE* next;  // 兄弟节点（语句链表）
} ASTNode;

ASTType 枚举包含约 30 种节点类型：

类型对应结构体用途
AST_LITERALAST_Literal字面量、标识符、函数调用
AST_BINARYAST_Binary二元运算表达式
AST_UNARYAST_Unary一元运算表达式
AST_VARAST_Var变量声明（带初始化）
AST_VAR_ASSAST_Var变量赋值
AST_UNINIT_VARAST_Var变量声明（未初始化）
AST_IFAST_Ifif/else if/else 语句
AST_SWITCHAST_Switchswitch/case 语句
AST_WHILEAST_Whilewhile/do-while 循环
AST_FORAST_Forfor 循环
AST_FOREACHAST_ForEachforeach 循环
AST_FUNCTIONAST_Function函数定义
AST_RETURNAST_Returnreturn 语句
AST_PRINTAST_Printprint 语句
AST_CLASS_DEFAST_ClassDef类定义
AST_ENUM_DEFAST_EnumDef枚举定义
AST_ARRAY_DECLAST_ArrayDecl数组声明
AST_ARRAY_ACCESSAST_ArrayAccess数组元素访问
AST_ARRAY_ASSAST_ArrayAss数组元素赋值

每个 AST 类型对应一个具体的结构体，它们都以 ASTNode 作为第一个字段（base），实现简单的继承：

typedef struct AST_BINARY {
    ASTNode base;           // 基类
    ASTNode* left;          // 左操作数
    Token op;               // 运算符
    ASTNode* right;         // 右操作数
    DataType resultType;    // 结果类型（语义分析后填充）
    bool is_unsigned;       // 是否无符号运算
} AST_Binary;

Symbol 与符号表

符号表用于语义分析阶段，存储变量、函数、类等符号的信息。定义在 Semantics.h：

typedef struct SYMBOL {
    struct SYMBOL* next;    // 链表（哈希桶）
    Token value;            // 词法信息
    DataType type;          // 数据类型
    char* key;              // 符号名
    char* internal_name;    // 编译器内部名（如 _var0）
    char* class_name;       // 所属类名（如果是类成员）
    int dim_count;          // 数组维度
    int* dim_sizes;         // 各维度大小
    bool is_field;          // 是否是类字段
    int field_offset;       // 字段在类中的偏移
    bool is_function;       // 是否是函数
    int field_modifier;     // 访问修饰符
} Symbol;

符号表使用作用域链组织：

typedef struct SCOPE {
    Symbol_Table* table;    // 当前作用域的哈希表
    struct SCOPE* parent;   // 父作用域
    int depth;              // 作用域深度
} Scope;

哈希表结构：

typedef struct SYMBOL_TABLE {
    Symbol** buckets;       // 哈希桶数组
    int count;              // 符号数量
    int size;               // 桶数量
} Symbol_Table;

IR（中间表示）

IR 是编译器中间层的核心数据结构，采用三地址码形式。定义在 IR.h：

typedef struct IR {
    IRType type;            // 指令类型
    char* result;           // 结果变量名
    int def_id;             // 定义 ID（用于 SSA）
    IR_OP_Type op;          // 操作类型（二元运算时使用）
    char* args1;            // 第一操作数
    int args1_def;          // 第一操作数的定义 ID
    DataType args1_type;    // 第一操作数类型
    char* args2;            // 第二操作数
    int args2_def;          // 第二操作数的定义 ID

错误处理系统

概述

YXG 编译器有一套完整的错误报告系统，贯穿编译的各个阶段。它能够精确报告错误位置、错误码、错误级别，并显示源代码上下文。

错误级别

系统定义了五种严重级别：

级别枚举值含义行为
致命错误SEV_FATAL无法继续编译立即终止程序
错误SEV_ERROR编译失败记录错误，继续检查
警告SEV_WARNING可能有问题记录警告，继续编译
提示SEV_NOTE附加信息仅输出，不影响编译
建议SEV_HINT修复建议仅输出，不影响编译

错误码体系

每个错误都有唯一的错误码，按阶段分类：

阶段错误码范围示例
词法分析E1001 ~ E1005E1001: 未终止的字符串
语法分析E2001 ~ E2006E2001: 意外的 Token
语义分析E3001 ~ E3020E3001: 未声明的变量
IR 生成E4001E4001: 空 AST 节点
代码生成E5001E5001: 未知变量
内部错误E9001 ~ E9004E9001: 内部编译器错误

错误报告格式

编译器输出包含文件名、行号、列号、错误级别、错误码和描述信息：

hello.yxg:5:10: error[E3001]: variable 'x' is not declared
    5 |     print x;
      |           ^

如果启用了颜色输出（默认），不同级别会显示不同颜色：

  • 红色：致命错误和普通错误
  • 黄色：警告
  • 青色：提示
  • 绿色：建议

源代码上下文

当错误发生在某一行时，编译器会显示该行的源代码并在错误位置标注 ^ 符号：

hello.yxg:3:5: error[E3003]: type mismatch: expected 'int', got 'string'
    3 |     int x = "hello";
      |     ^^^

这需要编译器在词法分析阶段记录源代码和位置信息。

错误恢复策略

不同阶段的错误恢复策略不同：

词法分析阶段

遇到无法识别的字符时，跳过该字符继续分析：

// 遇到非法字符 @
ERROR(ERR_LEX_UNKNOWN_CHAR, loc, "unexpected character '@'");
// 跳过该字符，继续词法分析

语法分析阶段

遇到语法错误时，使用恐慌模式恢复：跳过后续 Token 直到找到同步点（通常是分号、右花括号等）：

while (!parser_current_is_type(parser, TOKEN_SEMICOLON) &&
       !parser_current_is_type(parser, TOKEN_EOF) &&
       !is_Modifier(parser)) {
    parser_advance(parser);
}
if (parser_current_is_type(parser, TOKEN_SEMICOLON))
    parser_advance(parser);

语义分析阶段

遇到类型错误时，将节点类型标记为 DATA_ERROR 并继续分析，避免级联错误：

if (!types_compatible(declared, actual)) {
    ERROR(ERR_SEM_TYPE_MISMATCH, loc, "...");
    node->dataType = DATA_ERROR;  // 标记为错误，抑制后续级联错误
}

最大错误数限制

默认最多报告 100 个错误。超过后编译器停止报告并退出：

if (error_mgr->error_count >= error_mgr->options.max_errors) {

目标

import yxg.Math;
import yxg.String;

// 生成随机数组
int[] generateArray(int size, int maxValue) {
    Math m = new Math();
    m.srand(12345);

    int[] arr = new int[size];
    for int i = 0; i < size; i++ {
        arr[i] = m.randint(1, maxValue);
    }
    return arr;
}

// 打印数组
void printArray(string label, int[] arr) {
    print label;
    for int i = 0; i < arr.length; i++ {
        print arr[i];
    }
    print "";
}

// 冒泡排序
void bubbleSort(int[] arr) {
    int n = arr.length;
    for int i = 0; i < n - 1; i++ {
        for int j = 0; j < n - i - 1; j++ {
            if arr[j] > arr[j + 1] {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

// 选择排序
void selectionSort(int[] arr) {
    int n = arr.length;
    for int i = 0; i < n - 1; i++ {
        int minIdx = i;
        for int j = i + 1; j < n; j++ {
            if arr[j] < arr[minIdx] {
                minIdx = j;
            }
        }
        if minIdx != i {
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}

// 插入排序
void insertionSort(int[] arr) {
    int n = arr.length;
    for int i = 1; i < n; i++ {
        int key = arr[i];
        int j = i - 1;
        while j >= 0 && arr[j] > key {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

// 快速排序
void quickSort(int[] arr, int low, int high) {
    if low < high {
        int pivot = arr[high];
        int i = low - 1;

        for int j = low; j < high; j++ {
            if arr[j] <= pivot {
                i++;
                int temp = arr[i];
                arr[i] = arr[j];
                arr[j] = temp;
            }
        }

        int temp = arr[i + 1];
        arr[i + 1] = arr[high];
        arr[high] = temp;

        int pi = i + 1;
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

// 复制数组
int[] copyArray(int[] src) {
    int[] dst = new int[src.length];
    for int i = 0; i < src.length; i++ {
        dst[i] = src[i];
    }
    return dst;
}

// 验证数组是否有序
bool isSorted(int[] arr) {
    for int i = 0; i < arr.length - 1; i++ {
        if arr[i] > arr[i + 1] {
            return false;
        }
    }
    return true;
}

int main() {
    int size = 10;
    int maxValue = 100;

    int[] original = generateArray(size, maxValue);
    printArray("原始数组: ", original);
    print "";

    // 冒泡排序
    int[] arr1 = copyArray(original);
    bubbleSort(arr1);
    printArray("冒泡排序: ", arr1);
    print "有序:", isSorted(arr1);

    // 选择排序
    int[] arr2 = copyArray(original);
    selectionSort(arr2);
    printArray("选择排序: ", arr2);
    print "有序:", isSorted(arr2);

    // 插入排序
    int[] arr3 = copyArray(original);
    insertionSort(arr3);
    printArray("插入排序: ", arr3);
    print "有序:", isSorted(arr3);

    // 快速排序
    int[] arr4 = copyArray(original);
    quickSort(arr4, 0, arr4.length - 1);
    printArray("快速排序: ", arr4);
    print "有序:", isSorted(arr4);

    return 0;
}

实战教程：实现一个简单链表

目标

使用 YXG 的面向对象特性实现一个单向链表，支持添加、删除、查找和遍历操作。

完整代码

import yxg.String;

// 链表节点类
class Node {
    pub int data;
    pub Node next;

    pub Node(int data) {
        this.data = data;
        this.next = null;
    }
}

// 链表类
class LinkedList {
    pri Node head;
    pri int size;

    pub LinkedList() {
        this.head = null;
        this.size = 0;
    }

    // 在尾部添加节点
    pub void append(int data) {
        Node newNode = new Node(data);

        if head == null {
            head = newNode;
        } else {
            Node current = head;
            while current.next != null {
                current = current.next;
            }
            current.next = newNode;
        }

        size = size + 1;
    }

    // 在头部添加节点
    pub void prepend(int data) {
        Node newNode = new Node(data);
        newNode.next = head;
        head = newNode;
        size = size + 1;
    }

    // 在指定位置插入
    pub bool insert(int index, int data) {
        if index < 0 || index > size {
            print "插入位置无效:", index;
            return false;
        }

        if index == 0 {
            prepend(data);
            return true;
        }

        Node newNode = new Node(data);
        Node current = head;

        for int i = 0; i < index - 1; i++ {
            current = current.next;
        }

        newNode.next = current.next;
        current.next = newNode;
        size = size + 1;
        return true;
    }

    // 删除指定位置的节点
    pub bool removeAt(int index) {
        if index < 0 || index >= size {
            print "删除位置无效:", index;
            return false;
        }

        if index == 0 {
            head = head.next;
            size = size - 1;
            return true;
        }

        Node current = head;
        for int i = 0; i < index - 1; i++ {
            current = current.next;
        }

        current.next = current.next.next;
        size = size - 1;
        return true;
    }

    // 删除第一个值为 data 的节点
    pub bool remove(int data) {
        if head == null {
            return false;
        }

        if head.data == data {
            head = head.next;
            size = size - 1;
            return true;
        }

        Node current = head;
        while current.next != null {
            if current.next.data == data {
                current.next = current.next.next;
                size = size - 1;
                return true;
            }
            current = current.next;
        }

        return false;
    }

    // 查找节点位置
    pub int indexOf(int data) {
        Node current = head;
        int index = 0;

        while current != null {
            if current.data == data {
                return index;
            }
            current = current.next;
            index++;
        }

        return -1;
    }

    // 获取指定位置的节点值
    pub int get(int index) {
        if index < 0 || index >= size {
            print "索引越界:", index;
            return -1;
        }

        Node current = head;
        for int i = 0; i < index; i++ {
            current = current.next;
        }

        return current.data;
    }

    // 获取链表长度
    pub int getSize() {
        return size;
    }

    // 判断链表是否为空
    pub bool isEmpty() {
        return size == 0;
    }

    // 反转链表
    pub void reverse() {
        Node prev = null;
        Node current = head;
        Node next = null;

        while current != null {
            next = current.next;
            current.next = prev;
            prev = current;
            current = next;
        }

        head = prev;
    }

    // 打印链表
    pub void printList() {
        if head == null {
            print "链表为空";
            return;
        }

        Node current = head;
        while current != null {
            print current.data;
            current = current.next;
            if current != null {
                print " -> ";
            }
        }
        print "";
    }
}

int main() {
    LinkedList list = new LinkedList();

    print "=== 添加元素 ===";
    list.append(10);
    list.append(20);
    list.append(30);
    list.prepend(5);
    list.insert(2, 15);
    list.printList();
    print "链表长度:", list.getSize();

    print "";
    print "=== 查找元素 ===";
    print "索引 0 的值:", list.get(0);
    print "索引 3 的值:", list.get(3);
    print "值 20 的位置:", list.indexOf(20);
    print "值 100 的位置:", list.indexOf(100);

    print "";
    print "=== 删除元素 ===";
    list.removeAt(2);
    print "删除索引 2 后:";
    list.printList();

    list.remove(20);
    print "删除值 20 后:";
    list.printList();

    print "";
    print "=== 反转链表 ===";
    list.reverse();
    print "反转后:";
    list.printList();

    print "";
    print "=== 最终状态 ===";
    print "链表长度:", list.getSize();
    print "是否为空:", list.isEmpty();

    return 0;
}

import yxg.Math;
import yxg.System;

enum Operation {
    ADD = 1,
    SUB = 2,
    MUL = 3,
    DIV = 4
}

class Calculator {
    pri float memory;
    pri int opCount;

    pub Calculator() {
        this.memory = 0.0;
        this.opCount = 0;
    }

    pub float add(float a, float b) {
        opCount++;
        return a + b;
    }

    pub float sub(float a, float b) {
        opCount++;
        return a - b;
    }

    pub float mul(float a, float b) {
        opCount++;
        return a * b;
    }

    pub float div(float a, float b) {
        if b == 0.0 {
            print "错误: 除数不能为零";
            return 0.0;
        }
        opCount++;
        return a / b;
    }

    pub float power(int base, int exp) {
        Math m = new Math();
        opCount++;
        return m.pow(base, exp);
    }

    pub float sqrt(float x) {
        Math m = new Math();
        opCount++;
        return m.sqrt(x);
    }

    pub void store(float value) {
        memory = value;
        print "已存储:", memory;
    }

    pub float recall() {
        return memory;
    }

    pub void clearMemory() {
        memory = 0.0;
        print "存储器已清零";
    }

    pub int getOpCount() {
        return opCount;
    }

    pub void resetCount() {
        opCount = 0;
    }
}

                int base, exp;

附录：术语表

A

AST（抽象语法树） Abstract Syntax Tree。源代码经过语法分析后得到的树形数据结构，每个节点代表程序中的一个语法结构，如表达式、语句、声明等。

B

基本块（Basic Block） 一段顺序执行的指令序列，只有一个入口和一个出口。控制流图由基本块组成。

变量重命名（Variable Renaming） SSA 构造的第二步。遍历支配树，将每个变量的定义替换为带版本号的新名称，使用处替换为当前栈顶版本。

编译器前端（Compiler Frontend） 编译器的前三个阶段：词法分析、语法分析、语义分析。负责将源代码转换为标注类型的 AST。

编译器中端（Compiler Middle-end） 编译器在语义分析和代码生成之间的阶段。YXG 的中端包括 IR 生成、CFG 构建、SSA 构造和优化。

编译器后端（Compiler Backend） 编译器的最后阶段：寄存器分配和代码生成。负责将 IR 转换为目标平台的汇编代码。

C

CFG（控制流图） Control Flow Graph。由基本块和它们之间的跳转关系组成的有向图，表示程序的控制流结构。

常量传播（Constant Propagation） 一种编译器优化。将编译时已知的常量值替换到使用处，减少运行时计算。

常量折叠（Constant Folding） 一种编译器优化。在编译时计算常量表达式的结果，例如将 2+3 替换为 5。

成员访问控制 YXG 中控制类成员可见性的机制，包括 pub（公开）、pro（受保护）、pri（私有）三种级别。

D

递归下降分析（Recursive Descent Parsing） 一种手写语法分析器的方法。为每个语法规则编写一个函数，通过递归调用解析嵌套结构。

短路求值（Short-circuit Evaluation） 逻辑表达式的求值策略。对于 A && B，如果 A 为 false 则不计算 B；对于 A || B，如果 A 为 true 则不计算 B。

F

φ 节点（Phi Node） SSA 形式中的特殊节点，用于在控制流汇合点合并来自不同路径的变量值。

符号表（Symbol Table） 存储程序中所有标识符信息的数据结构，包括变量名、类型、作用域等。

G

getter / setter 编译器为 pri 字段自动生成的访问方法。getter 用于读取字段值，setter 用于修改字段值。

H

活跃分析（Liveness Analysis） 数据流分析的一种。确定每个变量在程序的哪些位置是“活跃的“（其值在后续会被使用）。

I

IR（中间表示） Intermediate Representation。编译器内部使用的、介于高级语言和机器语言之间的程序表示形式。YXG 使用三地址码形式的 IR。

J

寄存器分配（Register Allocation） 将程序中的虚拟变量映射到 CPU 物理寄存器的过程。YXG 使用 Chaitin-Briggs 图着色算法。

L

立即数（Immediate） 直接嵌入在指令中的常量值，如 mov eax, 42 中的 42。

令牌（Token） 词法分析器输出的最小语义单元，如关键字、标识符、运算符、字面量等。

N

NASM Netwide Assembler。YXG 编译器使用的 x86 汇编器，将 .asm 文件汇编为 .obj 目标文件。

P

parser（语法分析器） 将 Token 序列按照语法规则组织成 AST 的程序。

pub / pro / pri YXG 中的三种访问控制修饰符。pub 公开，pro 仅子类可访问，pri 仅本类可访问。

S

SSA（静态单赋值） Static Single Assignment。一种 IR 形式，要求每个变量只被赋值一次。通过 φ 节点合并不同控制流路径的值。

SSA 解构（SSA Destruction） 将 SSA 形式 IR 转换回普通 IR 的过程。移除 φ 节点，在前驱基本块末尾插入复制指令。

三地址码（Three-address Code） 一种 IR 形式，每条指令最多有三个操作数：两个源操作数和一个目标操作数，如 x = y + z。

T

图着色算法（Graph Coloring） 寄存器分配的核心算法。将变量视为图中的节点，冲突（同时活跃）的变量之间有边。用 k 种颜色（寄存器）给图着色，无法着色的变量溢出到栈上。

Y

YXG 语言 本书的主角——一门为教学设计的编译型编程语言，语法类似 C，支持面向对象。

YXG 编译器 将 YXG 源代码编译为 Windows 可执行文件的程序，完全用 C 语言手写。

Z

支配树（Dominator Tree） 控制流图的一种衍生结构。节点 A 支配节点 B 表示从入口到 B 的所有路径都必须经过 A。支配树以树形结构表示支配关系。

支配边界（Dominance Frontier） SSA 构造的关键概念。节点 B 的支配边界是那些不被 B 严格支配、但被 B 的某个前驱支配的节点的集合。φ 节点就插入在支配边界处。

中间代码生成（IR Generation） 将 AST 转换为 IR 的过程。遍历 AST，为每个节点生成对应的 IR 指令序列。
