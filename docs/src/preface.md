# 前言

## 这本书是什么？

这是一本 YXG 编程语言的入门教程。YXG 是一门为教学设计的类 C 静态类型语言，语法简洁、上手快速，同时支持面向对象、模块系统等现代语言特性。

本书将带你从零开始学习 YXG 语言，通过丰富的示例代码和实战项目，帮助你快速掌握这门语言。

## 适合谁读？

- 想要学习一门简洁的编译型语言的初学者
- 对编程语言设计感兴趣、想了解不同语言特性的开发者
- 正在寻找教学用编程语言的教师或学生

## 你需要什么基础？

- 了解基本的编程概念（变量、循环、函数等）
- 如果有 C 语言或 Java 的使用经验会更轻松，但不是必须的

## 关于 YXG 语言

YXG 是一门静态类型的编译型语言，语法风格接近 C 和 Java。它的设计目标是简单而不简陋——在保持语言核心简洁的同时，提供类型推导、面向对象、垃圾回收等现代特性。

YXG 编译器会将源码编译为 Windows 可执行文件，运行效率高，适合学习底层原理。

## 本书结构

本书分为四个部分：

**第一部分：快速入门。** 介绍 YXG 语言的基本语法，搭建编译环境，运行第一个程序。

**第二部分：YXG 语言参考。** 系统讲解 YXG 的所有语言特性，包括类型系统、控制流、函数、数组、字符串、面向对象、枚举和模块系统。

**第三部分：实战教程。** 通过三个完整的 YXG 程序巩固所学知识：排序程序、链表实现和命令行计算器。

**附录。** 编译错误码速查、术语表和参考资料。

## 如何使用本书？

如果你是完全的初学者，建议从第一部分开始按顺序阅读，边读边动手编写和运行示例代码。

如果你已经有一定的编程经验，可以快速浏览第一部分，然后直接跳到第二部分查阅感兴趣的语言特性，或者直接阅读第三部分的实战教程。
